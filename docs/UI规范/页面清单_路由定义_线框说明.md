# 页面清单 + 路由定义 + 线框说明（桌面端）

> 目标：采用 GPT/豆包/Minimax 类标准工作台布局，统一为三栏壳层（左导航 + 中工作区 + 右上下文栏）。
> 约束：严格使用 Semi Design 组件与已定义 design-token。

## 1. 全局布局（App Shell）

## 1.1 壳层结构
- 顶部全局栏：应用标题、全局搜索、全局设置、窗口操作。
- 左侧导航栏：一级模块切换 + 当前模块的任务/会话列表。
- 中央主工作区：当前页面核心操作区。
- 右侧上下文栏：参数配置、执行日志、详情信息（可折叠）。
- 底部状态栏：主操作按钮、执行状态、快捷键提示。

## 1.2 组件映射（Semi）
- 顶栏：`Layout.Header` + `Input` + `Button` + `Dropdown` + `Tooltip`
- 左栏：`Layout.Sider` + `Nav` + `Tabs` + `List`
- 中区：`Layout.Content` + `Card` + `Table` + `Form` + `Space`
- 右栏：`Layout.Sider` + `Collapse` + `Descriptions` + `Typography`
- 底栏：`Layout.Footer` + `Button` + `Tag` + `Progress`

## 1.3 建议尺寸
- Header：56
- 左栏：240（收起 72）
- 右栏：320（折叠 0）
- Footer：40
- 中区最小宽度：900

---

## 2. 路由定义

> 桌面端推荐使用 HashRouter，避免 Electron 打包路径问题。

## 2.1 路由表
1. `/#/agent/cases`
- 页面：Agent-用例管理
- 说明：用例 CRUD + 导入导出

2. `/#/agent/run`
- 页面：Agent-测试运行
- 说明：单条/批量运行 + 进度 + 日志

3. `/#/agent/stats`
- 页面：Agent-结果统计
- 说明：通过率/得分分布/失败分析

4. `/#/llmops/inspect`
- 页面：LLMOps-对话质量巡检
- 说明：输入对话并巡检

5. `/#/llmops/logs`
- 页面：LLMOps-模型调用日志
- 说明：日志查询/详情/导出

6. `/#/llmops/metrics`
- 页面：LLMOps-巡检指标可视化
- 说明：成功率、延迟、趋势

7. `/#/rlhf/generate`
- 页面：RLHF-生图生成
- 说明：提示词生图、预览、保存

8. `/#/rlhf/vlm`
- 页面：RLHF-VLM图片解析
- 说明：图片解析、反馈准确性

9. `/#/rlhf/labels`
- 页面：RLHF-标注管理
- 说明：评分、备注、历史与导出

10. `/#/settings`
- 页面：全局设置
- 说明：模型配置、主题、快捷键、数据路径

11. `/#/about`
- 页面：关于页
- 说明：版本信息、更新说明、问题反馈

## 3. 页面线框（按 Semi 组件粒度）

## 3.1 Agent-用例管理（`/#/agent/cases`）
- 顶部操作条：`Space`
- 按钮：`Button`（新增、导入、导出、批量删除）
- 搜索：`Input.Search`
- 主表格：`Table`
- 弹窗：`Modal` + `Form` + `Input.TextArea`
- 右栏详情：`Descriptions` + `Tag`

线框：
- 中区上：筛选/操作
- 中区中：用例表格
- 右栏：当前选中用例详情与最近运行摘要

## 3.2 Agent-测试运行（`/#/agent/run`）
- 操作条：`Button`（运行、批量运行、取消）
- 进度区：`Progress` + `Spin`
- 结果表：`Table`
- 日志抽屉：`SideSheet` 或 `Drawer`

线框：
- 中区上：任务运行控制
- 中区中：运行队列与结果
- 右栏：执行日志流 + 错误详情

## 3.3 Agent-结果统计（`/#/agent/stats`）
- 指标卡：`Card` + `Typography`
- 图表：`Card` + 图表组件（Semi Chart/Recharts）
- 失败列表：`Table`

线框：
- 中区上：3 个 KPI 卡片
- 中区下：左得分分布，右趋势图
- 底部：失败用例表

## 3.4 LLMOps-对话质量巡检（`/#/llmops/inspect`）
- 输入区：`Input.TextArea`
- 操作区：`Button`（开始巡检、导入、导出）
- 结果区：`Card` + `Tag` + `Typography`

线框：
- 中区上：对话输入
- 中区中：巡检结果卡
- 右栏：模型原始响应与巡检建议

## 3.5 LLMOps-模型调用日志（`/#/llmops/logs`）
- 筛选：`Form` + `Select` + `DatePicker`
- 表格：`Table`（支持展开）
- 操作：`Button`（导出、清空）

线框：
- 中区上：筛选条
- 中区下：日志表
- 右栏：当前日志详情（请求摘要、响应摘要、错误）

## 3.6 LLMOps-巡检指标可视化（`/#/llmops/metrics`）
- KPI：`Card`
- 趋势：图表组件
- 下钻：点击图表点跳日志页

线框：
- 中区上：成功率/平均延迟/平均得分
- 中区下：得分趋势 + 延迟趋势

## 3.7 RLHF-生图生成（`/#/rlhf/generate`）
- 参数：`Form` + `Input` + `Select`
- 操作：`Button`（生成、重生、保存）
- 预览：`Image`
- 历史：`Table` 或 `List`

线框：
- 中区左：生图参数
- 中区右：图片预览
- 下方：历史生成记录

## 3.8 RLHF-VLM 图片解析（`/#/rlhf/vlm`）
- 图片输入：`Upload` 或本地导入按钮
- 解析结果：`Card` + `Typography` + `Tag`
- 反馈：`RadioGroup` + `Button`

线框：
- 中区上：图片选择与解析按钮
- 中区中：解析文本与关键元素
- 右栏：原图信息 + 历史解析结果

## 3.9 RLHF-标注管理（`/#/rlhf/labels`）
- 打分：`Slider`
- 备注：`Input.TextArea`
- 提交：`Button`
- 历史：`Table` + `Tag`

线框：
- 中区左：当前对象与评分表单
- 中区右：历史标注列表
- 右栏：选中标注详情与导出按钮

## 3.10 全局设置（`/#/settings`）
- 分组：`Tabs` 或 `Collapse`
- 配置项：`Form` + `Switch` + `Input` + `Select`
- 保存：`Button`

线框：
- 中区：左侧设置分类，右侧配置表单

## 4. 页面状态规范（统一）
1. 首屏加载：`Skeleton` 或 `Spin`
2. 空数据：`Empty`
3. 错误态：`Result` + 重试按钮
4. 成功反馈：`Message.success`
5. 危险动作：`Modal.confirm`

---

## 5. 导航与交互规范
1. 左栏一级导航固定，模块内二级页面可用 `Tabs` 或子导航。
2. 右栏默认展开，可记忆用户最近开关状态。
3. 页面切换保留当前筛选状态（同模块内）。
4. 全局快捷键：
- `Ctrl/Cmd + K`：全局搜索
- `Ctrl/Cmd + S`：保存当前表单
- `Esc`：关闭右栏/弹窗

---

## 6. 开发落地顺序（建议）
1. 先做 `App Shell`（Header/Sider/Content/Context/Footer）
2. 再落 3 个主模块首页（cases / inspect / generate）
3. 再补运行、日志、统计、标注等子页
4. 最后接入设置页与全局快捷键

---

## 7. 验收清单
1. 所有页面遵循统一壳层结构。
2. 只使用 Semi 组件和 design-token。
3. 三个模块切换流畅，无布局跳变。
4. 125%/150% 缩放下布局稳定。
5. 右栏开关、筛选条件、滚动位置有合理记忆。
