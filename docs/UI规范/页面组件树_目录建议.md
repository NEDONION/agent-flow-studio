## 3. 路由分组建议
1. `agent/*`
2. `llmops/*`
3. `rlhf/*`
4. `settings`
5. `about`

## 4. 复用组件建议
1. `PageSectionCard`：统一页面区块容器（基于 `Card`）。
2. `PageToolbar`：统一筛选与操作栏（基于 `Space`）。
3. `StatusTag`：统一状态标签（基于 `Tag`）。
4. `AsyncState`：统一 loading/empty/error 三态。
5. `RightPanelBlock`：右栏区块容器（标题 + 内容 + 操作）。

## 5. 开发规则
1. 页面级组件只组装，不写复杂业务逻辑。
2. 业务逻辑下沉到 `modules/*` 与 `shared/services`。
3. 所有样式优先使用 Semi props 与 token，不单独造视觉体系。
