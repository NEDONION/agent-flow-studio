# 桌面端基础能力-前端文档

## 1. 功能目标
提供跨模块一致的桌面交互基础：导航、窗口状态感知、统一反馈、配置管理。

## 2. 页面与组件
- 顶部导航：三大模块 Tabs。
- 全局反馈：`Spin`、`Message`、`Notification`。
- 全局设置：主题、快捷键开关、数据路径显示。

## 3. 前端职责
- 统一路由与模块切换状态。
- 监听主进程事件（窗口状态、任务通知）。
- 通过 Preload API 调用系统能力（不直接使用 Node）。

## 4. 状态模型
- `appState`: 当前模块、窗口是否聚焦、是否置顶。
- `globalLoading`: 全局请求计数器。
- `settings`: `autoStart/topMost/shortcutEnabled/dataPath`。

## 5. 接口契约
- IPC `app:getState()`
- IPC `app:setWindow({ topMost })`
- IPC `app:setSetting(payload)`
- Event `app:windowChanged`
- Event `app:notify`

## 6. 验收标准
- 模块切换无白屏。
- 窗口状态变化可即时反映到 UI。
- 全局错误提示统一，文案可读。
