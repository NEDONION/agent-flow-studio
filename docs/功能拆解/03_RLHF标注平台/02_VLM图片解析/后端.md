# VLM图片解析-后端文档

## 1. 服务职责
- 接收图片输入并调用 VLM 模型输出描述。
- 记录解析结果与人工反馈，用于后续质量改进。

## 2. 数据模型
`VlmParse`
- `parseId`
- `sourceType: generated | local`
- `imageRef`
- `description`
- `entities[]`
- `confidence?`
- `createdAt`

`VlmFeedback`
- `parseId`
- `label: accurate | inaccurate`
- `comment?`
- `createdAt`

## 3. 接口定义
- `vlm:parse({ imagePath | imageUrl })`
- `vlm:importImage()`
- `vlm:feedback({ parseId, label, comment })`

## 4. 业务规则
- 本地图片需先复制到受控目录再解析。
- 解析失败可重试 1 次。
- 反馈一经提交允许覆盖最近一次反馈。

## 5. 异常处理
- 文件不可读：`IMAGE_READ_ERROR`。
- 模型解析失败：`VLM_PARSE_ERROR`。
- 结果为空：`VLM_EMPTY_RESULT`。

## 6. 安全要求
- 图片路径白名单校验。
- 不允许解析系统敏感目录文件。

## 7. 测试要点
- 多格式图片解析兼容性。
- 反馈覆盖逻辑正确。
- 解析日志与原图引用一致。
