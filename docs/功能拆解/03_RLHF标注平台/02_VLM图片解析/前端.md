# VLM图片解析-前端文档

## 1. 功能目标
对生成图或本地导入图片进行 VLM 解析，输出结构化描述并支持人工反馈。

## 2. 页面与组件
- 图片来源：当前生成图 / 本地导入。
- 操作区：开始解析、复制结果。
- 结果区：描述文本、关键元素标签、准确性反馈按钮。

## 3. 交互流程
1. 用户选择图片来源。
2. 点击“VLM 解析”触发请求。
3. 返回描述与关键元素列表。
4. 用户反馈“准确/不准确”并保存。

## 4. 状态模型
- `targetImage`
- `vlmResult`: `{ description, entities[], confidence? }`
- `feedback`: `accurate | inaccurate | null`
- `loading.parse`

## 5. 前端规则
- 支持格式：`.jpg/.jpeg/.png/.webp`。
- 图片大小限制（建议 <= 10MB）。
- 无图片时禁止触发解析。

## 6. 接口契约
- IPC `vlm:parse({ imagePath | imageUrl })`
- IPC `vlm:importImage()`
- IPC `vlm:feedback({ parseId, label, comment? })`

## 7. 验收标准
- 本地导入图片可直接解析。
- 解析结果可复制且格式清晰。
- 反馈提交后可在日志中追溯。
