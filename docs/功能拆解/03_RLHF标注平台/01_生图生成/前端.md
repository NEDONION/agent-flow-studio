# 生图生成-前端文档

## 1. 功能目标
调用生图模型生成图片，并支持预览、重生、保存与日志查看。

## 2. 页面与组件
- 输入区：提示词输入、风格/尺寸选择。
- 操作区：生成、重新生成、保存。
- 展示区：`Image` 预览 + 放大查看。
- 日志区：最近生成记录列表。

## 3. 交互流程
1. 用户输入提示词并选择参数。
2. 点击“生成图片”后显示加载状态。
3. 成功后展示图片与元信息。
4. 用户可保存到本地，或继续重生。

## 4. 状态模型
- `prompt`、`style`、`size`
- `image`: `{ url, width, height, seed }`
- `history[]`
- `loading.generate`

## 5. 前端规则
- 提示词长度限制（1~500）。
- 生成中禁止重复点击。
- 保存前检查图片资源可访问。

## 6. 接口契约
- IPC `image:generate({ prompt, style, size })`
- IPC `image:save({ imageId | imageUrl })`
- IPC `image:history({ page, pageSize })`

## 7. 验收标准
- 生成成功后 1 步可保存本地。
- 失败时能看到明确失败原因。
- 历史记录可回放查看。
