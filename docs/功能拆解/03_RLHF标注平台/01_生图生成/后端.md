# 生图生成-后端文档

## 1. 服务职责
- 封装生图模型调用。
- 管理生成任务状态与结果持久化。
- 提供图片保存与历史查询。

## 2. 数据模型
`ImageTask`
- `taskId`、`prompt`、`style`、`size`
- `status: pending | success | fail`
- `imageUrl`、`localPath?`
- `createdAt`

## 3. 接口定义
- `image:generate({ prompt, style, size })`
- `image:save({ imageId | imageUrl })`
- `image:history({ page, pageSize })`

## 4. 业务规则
- 默认超时 90s。
- 支持一次重试（网络错误）。
- 保存时自动按日期目录归档。

## 5. 异常处理
- 生成超时：`IMAGE_TIMEOUT`。
- 额度不足：`IMAGE_QUOTA_EXCEEDED`。
- 本地保存失败：`IMAGE_SAVE_ERROR`。

## 6. 安全要求
- 图片下载需校验 URL 白名单或签名。
- 保存路径限制在用户数据目录。

## 7. 测试要点
- 连续生成 20 次稳定。
- 断网场景错误可读。
- 图片保存后可重复打开。
