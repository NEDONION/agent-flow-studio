# RLHF标注管理-后端文档

## 1. 服务职责
- 存储并管理标注记录。
- 提供查询、明细和导出能力。
- 为后续训练样本准备结构化数据。

## 2. 数据模型
`LabelRecord`
- `labelId`
- `targetType: image | vlm`
- `targetId`
- `score: number`（0~10）
- `remark?: string`
- `operator?: string`
- `createdAt`

## 3. 接口定义
- `label:create(payload)`
- `label:list(query)`
- `label:detail({ labelId })`
- `label:export({ ids, format })`

## 4. 业务规则
- 同一对象允许多次标注，保留历史版本。
- 导出支持全量或按筛选条件导出。
- 可选生成训练格式（如 JSONL）作为后续扩展。

## 5. 异常处理
- 参数非法：`LABEL_INVALID_PARAM`。
- 持久化失败：`LABEL_SAVE_ERROR`。
- 导出失败：`LABEL_EXPORT_ERROR`。

## 6. 安全与权限
- 默认单机本地使用，无多租户权限系统。
- 若引入云同步，需补充用户身份与访问控制。

## 7. 测试要点
- 高频提交下数据不丢失。
- 导出文件结构与字段完整。
- 历史版本排序正确。
