# RLHF标注管理-前端文档

## 1. 功能目标
对生图质量与解析质量进行打分标注，形成可检索、可导出的标注记录。

## 2. 页面与组件
- 标注区：对象信息、`Slider(0-10)`、备注输入。
- 提交区：提交标注、重置。
- 历史区：标注列表（排序、筛选、详情）。

## 3. 交互流程
1. 用户选择标注对象（生图或解析结果）。
2. 拖动评分并填写备注（可选）。
3. 提交后写入历史列表。
4. 可按类型/时间筛选并导出 JSON。

## 4. 状态模型
- `targetType: image | vlm`
- `targetId`
- `score: number`
- `remark`
- `records[]`
- `filters`

## 5. 前端规则
- 分值范围 0~10，支持 0.5 步进（可选）。
- 未选择标注对象时禁用提交。
- 备注长度 <= 1000。

## 6. 接口契约
- IPC `label:create({ targetType, targetId, score, remark })`
- IPC `label:list({ page, pageSize, type, dateRange })`
- IPC `label:detail({ labelId })`
- IPC `label:export({ ids?, format: "json" })`

## 7. 验收标准
- 提交后历史列表即时可见。
- 筛选/排序结果准确。
- 导出 JSON 可被再次导入解析。
