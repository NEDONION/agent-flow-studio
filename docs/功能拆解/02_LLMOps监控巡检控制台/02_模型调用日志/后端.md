# 模型调用日志-后端文档

## 1. 服务职责
- 记录每次巡检调用的请求摘要、结果摘要与性能指标。
- 提供分页查询、详情查询、清理与导出能力。

## 2. 数据模型
`InspectLog`
- `id`
- `createdAt`
- `taskType`
- `latencyMs`
- `score`
- `status: success | fail | timeout`
- `inputPreview`
- `outputPreview`
- `errorCode?`
- `rawPath?`（可选，原始大文本落盘路径）

## 3. 存储策略
- 近期日志：本地 JSON/SQLite（二选一）。
- 原始大文本：按文件分片存储，日志仅保留引用。
- 清理策略：按条数或按时间保留（如 30 天）。

## 4. 接口定义
- `inspectLog:list(query)`
- `inspectLog:detail({ id })`
- `inspectLog:clear({ beforeDate })`
- `inspectLog:export({ format })`

## 5. 异常处理
- 查询失败：`LOG_READ_ERROR`。
- 清理失败：`LOG_CLEAR_ERROR`。
- 导出失败：`LOG_EXPORT_ERROR`。

## 6. 安全与合规
- 日志默认脱敏展示。
- 导出时可选“含原文/不含原文”。
- 导出文件追加生成时间与摘要说明。

## 7. 测试要点
- 分页与筛选组合查询准确。
- 大量日志（10 万）下查询性能可接受。
- 清理后磁盘空间释放符合预期。
