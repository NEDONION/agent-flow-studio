# 模型调用日志-前端文档

## 1. 功能目标
展示巡检调用日志，支持查询、展开详情、清空与导出。

## 2. 页面与组件
- 日志表格：时间、类型、耗时、分数、状态。
- 展开详情：输入摘要、输出摘要、错误信息。
- 工具栏：筛选、搜索、清空、导出。

## 3. 交互流程
1. 页面加载读取最近日志。
2. 用户按关键字/状态筛选。
3. 点击行展开查看完整上下文。
4. 选择清空后执行二次确认。

## 4. 状态模型
- `logs[]`
- `query`: `keyword/status/dateRange`
- `pagination`
- `expandedRowKeys`

## 5. 前端规则
- 默认仅展示最近 500 条。
- 超长文本折叠展示，支持“复制全文”。
- 清空操作必须二次确认。

## 6. 接口契约
- IPC `inspectLog:list(query)`
- IPC `inspectLog:detail({ id })`
- IPC `inspectLog:clear({ beforeDate? })`
- IPC `inspectLog:export({ format })`

## 7. 验收标准
- 展开详情不阻塞列表滚动。
- 清空后统计面板同步刷新。
- 日志导出可被外部工具读取。
