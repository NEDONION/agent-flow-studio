# 巡检指标可视化-后端文档

## 1. 服务职责
- 对巡检日志进行聚合计算，输出 KPI 与时序数据。
- 保证统计口径稳定并可追溯。

## 2. 指标定义
- 成功率：`success_count / total_count`。
- 平均延迟：`sum(latencyMs)/count`。
- 平均得分：`sum(score)/count(score exists)`。

## 3. 聚合策略
- 趋势默认返回最近 10 次。
- 可按时间范围、场景维度过滤。
- 支持增量聚合缓存，减少重复计算。

## 4. 接口定义
- `inspectMetrics:kpi({ dateRange, scene })`
- `inspectMetrics:trend({ dateRange, scene, limit })`

## 5. 异常处理
- 数据不足：返回空趋势与默认 KPI。
- 聚合失败：`METRIC_AGG_ERROR`。

## 6. 测试要点
- 同一时间窗口下多次请求结果一致。
- 边界时间点（00:00）归档正确。
- KPI 与日志样本手工对账一致。
