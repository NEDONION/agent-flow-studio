# 对话质量巡检-前端文档

## 1. 功能目标
输入对话内容后执行事实性/安全性/流畅度巡检，并展示评分与建议。

## 2. 页面与组件
- 输入区：`Input.TextArea`（支持粘贴多轮对话）。
- 操作区：开始巡检、导入文本、清空。
- 结果区：评分卡片 + 标签（通过/风险/待优化）。
- 导出区：导出文本/截图。

## 3. 交互流程
1. 用户输入或导入对话文本。
2. 点击“开始巡检”后进入加载态。
3. 返回巡检结果并分维度展示。
4. 用户可复制结果或导出文件用于复盘。

## 4. 状态模型
- `inputText`
- `inspectResult`: `{ score, factual, safety, fluency, suggestions[] }`
- `loading.inspect`
- `lastTaskId`

## 5. 前端规则
- 输入内容最小长度（如 10 字），空内容禁止提交。
- 超长文本（如 > 20k 字）提示分段巡检。
- 结果标签颜色统一：绿/黄/红。

## 6. 接口契约
- IPC `inspect:start({ text, scene })`
- IPC `inspect:importText()`
- IPC `inspect:export({ format: "txt" | "png" })`

## 7. 验收标准
- 提交后有明显加载反馈。
- 结果字段完整（分数、结论、建议）。
- 导入/导出失败时有清晰错误提示。
