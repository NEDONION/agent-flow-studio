# 对话质量巡检-后端文档

## 1. 服务职责
- 接收对话文本，构建巡检提示词并调用 LLM。
- 解析并标准化模型输出为结构化结果。

## 2. 数据模型
`InspectRequest`
- `taskId`
- `text`
- `scene`（客服/通用/内部助手等）

`InspectResult`
- `score: number`
- `factual: "pass" | "fail" | "unknown"`
- `safety: "safe" | "risk"`
- `fluency: "good" | "normal" | "poor"`
- `suggestions: string[]`
- `raw`

## 3. 接口定义
- `inspect:start({ text, scene }) -> InspectResult`
- `inspect:importText()`（文件选择 + 读取）
- `inspect:export({ format })`

## 4. 业务规则
- 分数区间 0~100。
- 评分阈值：>=80 视为通过。
- 模型输出需二次校验，不合法时降级返回默认结构。

## 5. 异常处理
- 上游不可用：`MODEL_UNAVAILABLE`。
- JSON 解析失败：`PARSE_ERROR`，附原始文本截断。
- 文本过长：`INPUT_TOO_LARGE`，建议拆分。

## 6. 安全要求
- 对输入文本做敏感信息检测与掩码（可选）。
- 巡检日志默认不上传外部，仅本地留存。

## 7. 测试要点
- 异常模型返回下仍能输出结构化结果。
- 评分边界值（79/80）判定正确。
