# 结果统计-后端文档

## 1. 服务职责
- 从运行日志聚合统计指标。
- 向前端提供摘要、分布、趋势和失败明细。

## 2. 数据来源
- 用例主数据：`cases`。
- 执行日志：`run_logs`。
- 可选缓存：`stats_cache`（按时间范围缓存聚合结果）。

## 3. 聚合规则
- 通过率：`passed_runs / total_runs`。
- 平均分：`sum(score)/count(score)`。
- 趋势：按日或按小时聚合。
- 失败集合：`score < 80` 并按最近失败时间排序。

## 4. IPC/接口定义
- `stats:summary({ dateRange, scope })`
- `stats:distribution({ dateRange, bucket })`
- `stats:trend({ dateRange, interval })`
- `stats:failedCases({ dateRange, limit })`

## 5. 性能要求
- 10 万条日志内聚合响应目标 < 300ms（本地环境）。
- 对重复查询应用短期缓存（30~60 秒）。

## 6. 异常处理
- 数据集为空：返回空数组与默认值，不抛异常。
- 日志结构损坏：跳过坏记录并写告警日志。

## 7. 测试要点
- 口径切换（最近一次/全部）一致性。
- 边界分桶（79/80/89/90）准确。
- 时间区间跨时区时统计正确。
