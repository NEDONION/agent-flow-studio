# 结果统计-前端文档

## 1. 功能目标
将测试结果转化为可视化指标，帮助快速判断质量趋势与失败分布。

## 2. 页面与组件
- 指标卡：通过率、平均分、失败数。
- 图表区：得分分布柱状图、最近运行趋势线图。
- 列表区：失败用例 TopN。

## 3. 交互流程
1. 用户进入页面自动加载统计摘要。
2. 支持按时间范围筛选（今天/7天/30天/全部）。
3. 点击失败用例跳转到用例详情与日志。

## 4. 状态模型
- `summary`: `{ passRate, avgScore, totalRuns, failCount }`
- `distribution[]`: 分段计数（0-59/60-79/80-89/90-100）
- `trend[]`: 按时间序列统计
- `filters`: `dateRange`, `caseGroup`

## 5. 前端规则
- 统计口径默认“最近一次结果”，可切换“全部运行记录”。
- 图表空数据时展示空态引导，不展示错误图。

## 6. 接口契约
- IPC `stats:summary({ dateRange, scope })`
- IPC `stats:distribution({ dateRange, bucket })`
- IPC `stats:trend({ dateRange, interval })`
- IPC `stats:failedCases({ dateRange, limit })`

## 7. 验收标准
- 图表与指标卡口径一致。
- 切换筛选时 1 秒内完成重绘。
- 无历史数据时空态清晰，不误导用户。
