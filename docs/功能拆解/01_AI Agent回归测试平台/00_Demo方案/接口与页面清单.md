# AI Agent 回归测试平台（Demo）接口与页面清单

## 1. Demo范围
- 四业务统一评测：客服、销售、代码、数据分析。
- 用例管理、批量运行、基线对比、结果看板、失败复盘。
- 支持 Demo 回放模式（无真实模型也能稳定演示）。

## 2. 关键数据结构

### 2.1 TestCase
- `id: string`
- `bizType: "customer_service" | "sales" | "coding" | "data_analysis"`
- `scenario: string`
- `riskLevel: "low" | "medium" | "high"`
- `prompt: string`
- `expected: string`
- `hardRules: string[]`
- `rubric: { name: string; weight: number }[]`
- `tags: string[]`

### 2.2 RunSession
- `runId: string`
- `name: string`（如 `v1.2.0-candidate`）
- `mode: "live" | "replay"`
- `status: "running" | "done" | "canceled" | "failed"`
- `caseCount: number`
- `startedAt: string`
- `endedAt?: string`

### 2.3 RunResult
- `runId: string`
- `caseId: string`
- `bizType: string`
- `score: number`
- `passed: boolean`
- `reason: string`
- `latencyMs: number`
- `rawOutput?: unknown`

### 2.4 RegressionDiff
- `caseId: string`
- `baselineScore: number`
- `candidateScore: number`
- `delta: number`
- `regressed: boolean`
- `severity: "low" | "medium" | "high"`

## 3. 接口清单（IPC）

### 3.1 用例管理
- `case:list({ page, pageSize, keyword, bizType, riskLevel, tags })`
- `case:create(payload)`
- `case:update(payload)`
- `case:delete({ ids })`
- `case:import({ mode: "replace" | "merge" })`
- `case:export({ ids? })`

### 3.2 测试运行
- `run:start({ name, caseIds, concurrency, timeoutSec, mode, modelConfig }) -> { runId }`
- `run:cancel({ runId })`
- `run:get({ runId })`
- Event `run:progress({ runId, total, done, success, failed, canceled })`
- Event `run:result({ runId, caseId, score, passed, reason, latencyMs })`
- Event `run:log({ runId, caseId, level, message, timestamp })`

### 3.3 回归对比
- `regression:compare({ baselineRunId, candidateRunId }) -> { summary, diffs }`

### 3.4 结果统计
- `stats:summary({ runId?, bizType?, scope })`
- `stats:distribution({ runId?, bizType?, bucket })`
- `stats:trend({ bizType?, dateRange, interval })`
- `stats:failedCases({ runId?, bizType?, limit })`

## 4. 页面清单

### 4.1 用例管理页
- 筛选字段：`keyword/bizType/riskLevel/tags`
- 表格列：`id bizType scenario riskLevel prompt lastScore passRate updatedAt`
- 操作：新增、编辑、删除、导入、导出、批量运行

### 4.2 测试运行页
- 顶部配置：`runName mode concurrency timeout`
- 中部进度：`total done success failed canceled`
- 底部列表：当前队列 + 实时结果 + 日志抽屉

### 4.3 结果中心页
- 指标卡：`通过率 平均分 失败数 退化数`
- 图表：`得分分布 趋势图`
- 列表：`失败TopN`
- 对比区：`Baseline vs Candidate`（delta高亮）

### 4.4 失败详情抽屉
- 展示：`prompt expected baseline_output candidate_output score_diff reason`
- 操作：`标记已确认`、`加入回归必测集`

## 5. Demo演示流程（8分钟）
1. 导入 `cases.demo.json`（24条）。
2. 运行 `Baseline`（replay）。
3. 运行 `Candidate`（replay，包含4条退化）。
4. 打开结果中心，展示通过率与退化数变化。
5. 点开每业务1条退化详情（共4条）。
6. 输出发布结论：`Pass / Block / Review`。

## 6. Demo门禁建议
- 总通过率 >= 90%
- 高风险用例退化数 = 0
- 四业务中任一业务通过率 < 85% 则 `Block`

## 7. 第一版开发优先级
- P0: 用例管理、运行、结果、对比、失败详情。
- P1: 趋势、报告导出、门禁规则可配置。
- P2: 云同步、权限、CI接入。
