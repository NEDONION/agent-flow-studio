# 测试运行-前端文档

## 1. 功能目标
支持单条/批量测试运行，实时反馈执行进度、得分和通过结果。

## 2. 页面与组件
- 行内操作：单条“运行测试”按钮。
- 批量操作栏：批量运行、停止运行。
- 进度组件：`Progress`、`Spin`。
- 日志抽屉：查看每条执行轨迹。

## 3. 交互流程
1. 单条运行：点击后进入 loading -> 返回分数与建议 -> 更新当前行。
2. 批量运行：选择多条后启动任务队列 -> 显示总进度与当前任务。
3. 终止运行：用户主动终止，未开始任务标记为取消。
4. 查看详情：点击日志查看本次请求参数、耗时、结果摘要。

## 4. 状态模型
- `runQueue[]`: 待执行队列。
- `runningMap`: 当前执行中的 caseId 集合。
- `runResultMap`: caseId -> score/result/reason。
- `batchProgress`: `{ total, done, success, failed, canceled }`。

## 5. 前端规则
- 批量并发数可配置（默认 3）。
- 同一用例运行中不可重复触发。
- 超时默认 60s，超时后标记失败并允许重试。

## 6. 接口契约
- IPC `run:single({ caseId })`
- IPC `run:batch({ caseIds, concurrency })`
- IPC `run:cancel({ taskId })`
- IPC Event `run:progress`（推送进度）
- IPC Event `run:log`（推送执行日志）

## 7. 错误处理
- 模型超时：展示“请求超时，可重试”。
- API 配置缺失：展示“请先配置模型密钥”。
- 网络错误：分级提示（短暂失败/不可达）。

## 8. 验收标准
- 单测运行 3 秒内出现可感知状态变化。
- 批量运行进度与实际完成数量一致。
- 中途取消后状态准确，不出现“幽灵运行中”。
