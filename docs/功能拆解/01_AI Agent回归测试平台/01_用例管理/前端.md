# 用例管理-前端文档

## 1. 功能目标
提供测试用例的新增、编辑、删除、查询、导入、导出能力，作为测试运行的数据入口。

## 2. 页面与组件
- 页面区域：左侧筛选区 + 右侧用例表格区。
- 核心组件：`Table`、`Input.Search`、`Button`、`Modal`、`Form`、`Message`。
- 关键弹窗：新增/编辑用例弹窗、批量删除确认弹窗。

## 3. 交互流程
1. 用户点击“新增用例” -> 打开表单 -> 提交后刷新表格。
2. 用户点击“编辑” -> 回填数据 -> 提交后局部更新列表。
3. 用户勾选多行后点击“删除” -> 二次确认 -> 删除成功后更新分页与统计。
4. 用户点击“导入 JSON” -> 选择文件 -> 预校验 -> 导入结果提示。
5. 用户点击“导出 JSON” -> 选择路径 -> 导出成功提示。

## 4. 状态模型
- 列表状态：`cases[]`、`total`、`page`、`pageSize`、`selectedIds[]`。
- 查询状态：`keyword`、`statusFilter`。
- 弹窗状态：`isCreateOpen`、`isEditOpen`、`editingCaseId`。
- 请求状态：`loading.list`、`loading.submit`、`loading.import`、`loading.export`。

## 5. 前端校验规则
- Prompt 必填，长度 1~4000。
- 描述可选，长度 <= 500。
- 导入文件仅允许 `.json`，单文件大小建议 <= 5MB。
- 导入时校验字段：`id/prompt/description` 至少满足最小结构。

## 6. 接口契约
- IPC `case:list(query)`
- IPC `case:create(payload)`
- IPC `case:update(payload)`
- IPC `case:delete(ids)`
- IPC `case:import()`（由主进程拉起文件选择）
- IPC `case:export(filter)`

返回统一结构：`{ code, message, data, requestId }`。

## 7. 异常与提示
- 参数校验失败：表单内联错误提示。
- 文件格式错误：`Message.error("导入文件格式不正确")`。
- 存储失败：提示“本地写入失败，请检查磁盘权限”。

## 8. 验收标准
- 1000 条数据下分页与搜索响应正常。
- 导入非法 JSON 不导致页面崩溃。
- 新增/编辑/删除后列表与选择状态一致。
