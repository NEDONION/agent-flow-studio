# 功能拆解总览（agent-flow-studio）

## 1. 文档目标
按功能点沉淀可执行的前后端设计文档，支撑桌面端版本落地与后续迭代。

## 2. 前后端边界定义
本项目为桌面端应用，后端拆为两层：
- 本地后端：Electron Main + Preload + Node 能力（IPC、文件系统、托盘、通知、窗口管理）。
- 远端后端（可选）：统一模型网关与鉴权服务（LLM/VLM/生图 API 聚合）。

前端为 Electron Renderer（React + TypeScript + Semi Design），不直接访问 Node API，统一通过 Preload 暴露的安全接口。

## 3. 模块与功能点清单
1. AI Agent 回归测试平台
- 用例管理
- 测试运行
- 结果统计

2. LLMOps 监控巡检控制台
- 对话质量巡检
- 模型调用日志
- 巡检指标可视化

3. RLHF 标注平台
- 生图生成
- VLM 图片解析
- RLHF 标注管理

4. 全局能力
- 桌面端基础能力（导航、窗口、托盘、存储、异常）

## 4. 文档产物规范
每个功能点均包含：
- 前端文档（`前端.md`）：页面结构、交互流程、状态模型、接口契约、验收标准。
- 后端文档（`后端.md`）：服务边界、数据模型、接口定义、异常与安全、测试要点。
